# Patch licensing

The repository's original tooling, documentation, tests, and fixture
content are MIT licensed. The full text is in [LICENSE](LICENSE).

Patch files need a more careful boundary. A patch may contain original
work, copied context, or a transformation of an upstream work. This
repository's MIT notice applies only to original material that 4evy can
license. It does not relicense upstream source code, copied context, or
third-party material. Keep the upstream copyright and license notices.

If a patch is accepted upstream, the upstream project's contribution
rules and license govern the copy in that upstream project. That change
is not automatic, and this repository cannot promise to change another
project's license. If an upstream project later sends a change back
here, the license of that contribution is whatever the project and its
author actually grant. Record that provenance in the patch header when
it is known.

This is a practical repository policy, not legal advice. When a patch
contains substantial upstream code, a contributor's employer owns the
work, or the upstream project has special contribution terms, check with
the relevant copyright holder or a qualified lawyer before distributing
it.
